# Day 16. 단일 연결 리스트 역순 정렬

## 문제 설명

단일 연결 리스트(Singly Linked List)의 노드 연결 방향을 반대로 변경하여 리스트를 역순으로 정렬한다.

기존 리스트의 노드를 새로 생성하거나 메모리를 재할당하지 않고, 각 노드의 `next` 포인터만 변경하여 구현한다.

## 요구사항

* **입력:** `1 -> 2 -> 3 -> NULL`
* **출력:** `3 -> 2 -> 1 -> NULL`
* **제약조건:**

  * 메모리 재할당 없이 구현
  * 기존 노드를 그대로 사용
  * `next` 포인터의 방향만 변경
  * 연결 리스트의 모든 노드를 역순으로 연결

## 실행 결과

```text
List Reversed.
```

## 실행 과정

초기 연결 리스트는 다음과 같다.

```text
1 -> 2 -> 3 -> NULL
```

각 노드의 `next` 포인터 방향을 반대로 변경한다.

```text
1 <- 2 <- 3
```

역순으로 변경한 후 Head가 마지막 노드를 가리키도록 변경한다.

```text
3 -> 2 -> 1 -> NULL
```

## 핵심 알고리즘

연결 리스트를 순회하면서 현재 노드의 `next`가 가리키던 다음 노드를 먼저 저장한 후, 현재 노드의 `next` 방향을 이전 노드로 변경한다.

```text
prev = NULL
curr = head

        curr
         ↓
1 -> 2 -> 3 -> NULL
```

첫 번째 노드의 방향을 변경하면:

```text
NULL <- 1    2 -> 3 -> NULL
       ↑
      prev
```

이 과정을 반복한다.

최종적으로:

```text
NULL <- 1 <- 2 <- 3
                   ↑
                  head
```

따라서 새로운 Head는 기존 리스트의 마지막 노드인 `3`이 된다.

## 구현 시 주의사항

현재 노드의 `next`를 변경하기 전에 **기존 `next` 주소를 반드시 저장해야 한다.**

```c
next = curr->next;
curr->next = prev;
prev = curr;
curr = next;
```

`next`를 저장하지 않고 바로 `curr->next`를 변경하면 다음 노드로 이동할 수 있는 주소를 잃어버릴 수 있다.

## 시간 및 공간 복잡도

* **시간 복잡도:** `O(N)`

  * 모든 노드를 한 번씩 순회한다.
* **공간 복잡도:** `O(1)`

  * 새로운 노드를 생성하지 않고 포인터 변수만 사용한다.
