# Day 23. 문자열 토크나이저 (strtok 재구현)

## 문제 설명

문자열을 특정 구분자(delimiter)를 기준으로 여러 개의 토큰으로 분리하는 **문자열 토크나이저(String Tokenizer)** 를 구현한다.

C 표준 라이브러리의 `strtok()` 함수와 유사하게 동작하도록 구현하며, 내부의 `static` 변수를 사용하여 이전 호출에서 처리한 위치를 기억하도록 한다.

추가적으로 원본 문자열을 직접 수정하지 않고 파싱할 수 있도록 구현한다.

## 요구사항

* **입력:** `"GPS,37.5,127.0"` 형태의 문자열과 구분자 `','`
* **출력:** 구분자를 기준으로 순차적으로 파싱된 문자열
* **제약조건:**

  * 내부 `static` 변수를 사용하여 파싱 상태 저장
  * `static` 변수를 통해 이전 호출 위치 유지
  * 원본 문자열을 수정하지 않는 방식으로 구현
  * 마지막 토큰까지 순차적으로 반환

## 입력 예시

```text id="8x7r3n"
Input Data: "GPS,37.5665,126.9780,20260213"
Delimiter : ','
```

입력 문자열을 `,`를 기준으로 분리하면 다음과 같다.

```text id="0k4h91"
GPS
37.5665
126.9780
20260213
```

## 실행 결과

```text id="0y5qz7"

Delimiter : ','

Token 4: 20260213

>> Original string check: "GPS,37.5665,126.9780,20260213"
>> (Original string remains unmodified)
```

## 실행 과정

### Token 1

처음 함수를 호출할 때 입력 문자열의 시작 주소를 `static` 변수에 저장한다.

```text id="p8u8u0"
GPS,37.5665,126.9780,20260213
↑
현재 위치
```

`,`를 만날 때까지 문자를 읽어 첫 번째 토큰을 얻는다.

```text id="7q8o0a"
GPS
```

### Token 2

다음 호출에서는 이전에 저장된 위치부터 다시 탐색한다.

```text id="4b2r7q"
GPS,37.5665,126.9780,20260213
    ↑
  현재 위치
```

결과:

```text id="c2sm9e"
37.5665
```

### Token 3

다음 구분자까지 탐색한다.

```text id="q4b1kt"
126.9780
```

### Token 4

마지막 구분자 이후부터 문자열의 `NULL` 문자까지 읽어 마지막 토큰을 반환한다.

```text id="s9a0rj"
20260213
```

## 핵심 개념

### Static 변수

일반적인 지역 변수는 함수가 종료되면 값이 유지되지 않는다.

반면 `static` 지역 변수는 함수가 종료된 후에도 값이 유지된다.

```c
static const char* func_data = NULL;
```

따라서 첫 번째 호출에서는 문자열의 시작 위치를 저장하고, 이후 호출에서는 이전에 저장된 위치에서 계속 파싱할 수 있다.

```text id="j1z9e5"
1번째 호출
    ↓
문자열 시작 위치 저장
    ↓
"GPS" 반환

2번째 호출
    ↓
이전 위치에서 계속 탐색
    ↓
"37.5665" 반환

3번째 호출
    ↓
"126.9780" 반환

4번째 호출
    ↓
"20260213" 반환
```

### 원본 문자열 보호

일반적인 `strtok()`는 구분자를 `'\0'`으로 변경하기 때문에 원본 문자열이 수정된다.

이번 구현에서는 원본 문자열의 내용을 변경하지 않고 별도의 버퍼에 토큰을 복사하거나 길이를 이용하여 출력하는 방식으로 구현할 수 있다.

따라서 파싱 이후에도 원본 문자열을 그대로 확인할 수 있다.

```text id="5s3w9k"
Original:
"GPS,37.5665,126.9780,20260213"

Parsing 후:
"GPS,37.5665,126.9780,20260213"
```

## 파싱 구조

```text id="zq3c8x"
GPS,37.5665,126.9780,20260213
 │     │       │       │
 ↓     ↓       ↓       ↓
GPS   37.5665 126.9780 20260213
```

구분자 `,`를 기준으로 각각의 토큰을 분리한다.
