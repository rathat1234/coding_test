# Day 25. 이동 평균 필터 (Moving Average)

## 문제 설명

센서에서 측정되는 데이터에는 순간적인 노이즈나 튀는 값이 포함될 수 있다.

이러한 데이터를 안정화하기 위해 최근 `N`개의 데이터를 이용하여 평균을 계산하는 **이동 평균 필터(Moving Average Filter)** 를 구현한다.

매번 윈도우 전체의 합계를 다시 계산하지 않고, 새 데이터는 합계에 더하고 가장 오래된 데이터는 빼는 **Sliding Window 방식**을 사용하여 연산량을 줄인다.

추가적으로 현재 평균값을 기준으로 일정 범위를 크게 벗어나는 값은 이상치로 판단하여 필터 계산에 포함하지 않는다.

## 요구사항

* **입력:** 센서 노이즈 데이터 스트림
* **출력:** 이동 평균을 적용한 필터링 값
* **제약조건:**

  * 최근 `N`개의 데이터를 저장하는 Window Buffer 사용
  * 매번 모든 데이터를 더하지 않고 Sliding Window 방식으로 합계 관리
  * 윈도우가 가득 차기 전에는 현재 저장된 데이터 개수만큼 평균 계산
  * 현재 평균값을 기준으로 **±50% 범위 안의 값만 허용**
  * 허용 범위를 벗어나는 입력값은 이상치로 판단하여 필터에서 제외

## 실행 결과

```text
=== Day 25: Moving Average Filter (Sliding Window) ===
Window Size: 5

Step | Raw Input | Filtered Output
-----+-----------+----------------
   1 |    20.0   |       20.0  (1개 평균)
   2 |    22.0   |       21.0  (2개 평균)
   3 |    18.0   |       20.0  (3개 평균: 20+22+18 / 3)
   4 |    25.0   |       21.2
   5 |    15.0   |       20.0  (5개 꽉 참)
   6 |    20.0   |       20.0  (20.0이 들어오고, 맨 처음 20.0이 빠짐)
   7 |    21.0   |       19.8  (21.0이 들어오고, 22.0이 빠짐 -> 평균 하락)
   8 |    19.0   |       20.0
   9 |    20.5   |       19.1
  10 |    20.0   |       20.1
```

## 핵심 개념

### Moving Average

최근 일정 개수의 데이터를 이용하여 평균을 구한다.

Window Size가 `5`일 경우 최근 5개의 데이터만 평균 계산에 사용한다.

```text
20, 22, 18, 25, 15
```

평균은 다음과 같다.

```text
(20 + 22 + 18 + 25 + 15) / 5
= 20.0
```

이동 평균을 사용하면 순간적인 센서 값의 변화가 완화되어 보다 안정적인 데이터를 얻을 수 있다.

## Sliding Window

일반적으로 이동 평균을 계산할 때마다 윈도우 내부의 모든 값을 다시 더할 수 있다.

```text
20 + 22 + 18 + 25 + 15
```

하지만 Window Size가 커지거나 센서 샘플링 주기가 빨라지면 불필요한 연산이 반복된다.

따라서 기존 합계를 저장하여 사용한다.

```text
현재 합계
    ↓
기존 데이터 제거
    ↓
새 데이터 추가
    ↓
새로운 평균 계산
```

예를 들어 현재 데이터가 다음과 같다고 한다.

```text
[20] [22] [18] [25] [15]

Sum = 100
Average = 20
```

새로운 `20`이 들어오면 가장 오래된 `20`을 제거한다.

```text
Sum = 100 - 20 + 20
    = 100
```

따라서 전체 배열을 다시 더할 필요가 없다.

```text
[20] [22] [18] [25] [15]
  ↑
 제거

                ↓
            새로운 20
```

결과:

```text
[20] [22] [18] [25] [15]

Average = 100 / 5
        = 20.0
```

## 원형 버퍼와 Sliding Window

Window Buffer는 고정된 크기를 가지므로 새로운 데이터가 들어올 때 가장 오래된 데이터 위치를 다시 사용하는 **원형 버퍼 방식**으로 관리할 수 있다.

```text
Window Size = 5

Index
  0      1      2      3      4
+------+------+------+------+------+
| 20.0 | 22.0 | 18.0 | 25.0 | 15.0 |
+------+------+------+------+------+
   ↑
 oldest
```

다음 값이 들어오면 Index 0을 덮어쓴다.

```text
New Data = 20.0

+------+------+------+------+------+
| 20.0 | 22.0 | 18.0 | 25.0 | 15.0 |
+------+------+------+------+------+

         ↑
   다음 교체 위치
```

인덱스는 다음과 같이 순환시킬 수 있다.

```c
index = (index + 1) % WINDOW_SIZE;
```

## 실행 과정

### Phase 1. Window가 가득 차기 전

처음에는 저장된 데이터 개수가 Window Size보다 작기 때문에 실제 저장된 개수만 이용하여 평균을 계산한다.

첫 번째 입력:

```text
20.0
```

```text
Average = 20.0 / 1
        = 20.0
```

두 번째 입력:

```text
20.0, 22.0
```

```text
Average = 42.0 / 2
        = 21.0
```

세 번째 입력:

```text
20.0, 22.0, 18.0
```

```text
Average = 60.0 / 3
        = 20.0
```

### Phase 2. Window가 가득 찬 상태

5개의 값이 저장되면 Window가 가득 찬다.

```text
20.0, 22.0, 18.0, 25.0, 15.0
```

```text
Sum     = 100
Average = 20.0
```

이제부터 새로운 데이터가 들어올 때마다 가장 오래된 데이터를 제거한다.

### Phase 3. Sliding Window 동작

Step 7에서 새로운 값 `21.0`이 들어온다.

기존 데이터:

```text
20, 22, 18, 25, 15
```

Step 6에서 첫 번째 `20`이 새로운 `20`으로 교체된 후 다음으로 오래된 데이터는 `22`이다.

따라서:

```text
Old Sum = 100

100 - 22 + 21
= 99
```

평균:

```text
99 / 5 = 19.8
```

결과:

```text
Filtered Output = 19.8
```

## 이상치 제거

이번 구현에서는 현재 평균값을 기준으로 **50% 범위 안에 있는 입력만 필터에 적용**한다.

예를 들어 현재 평균값이 다음과 같다고 한다.

```text
Average = 20.0
```

허용 범위는:

```text
최소값 = 20.0 × 0.5 = 10.0
최대값 = 20.0 × 1.5 = 30.0
```

따라서 다음 값들은 정상 입력으로 판단할 수 있다.

```text
15
20
25
30
```

반면 다음과 같은 값은 이상치로 판단한다.

```text
5
40
100
```

예를 들어 센서에서 순간적으로 `100`이 들어오더라도 기존 Window에 넣지 않는다.

```text
Current Average = 20

New Data = 100

허용 범위 = 10 ~ 30

100 > 30
    ↓
Outlier
    ↓
Discard
```

따라서 순간적으로 발생하는 큰 센서 노이즈가 이동 평균 자체를 크게 흔드는 것을 방지할 수 있다.

> 초기 데이터처럼 아직 기준 평균이 없는 경우에는 첫 번째 값을 정상 데이터로 받아 평균값을 생성해야 한다.

## 알고리즘 구조

```text
새 센서 데이터 입력
        ↓
현재 평균 존재?
   ↓          ↓
  No         Yes
   ↓          ↓
데이터 저장   ±50% 범위 검사
                 ↓
          범위 안에 있는가?
             ↓       ↓
            Yes      No
             ↓        ↓
         Window 저장  버림
             ↓
      기존 값 Sum에서 제거
             ↓
       새 값 Sum에 추가
             ↓

```

## 시간 및 공간 복잡도

### 일반적인 이동 평균

매번 Window 전체의 합을 다시 계산하면 Window Size를 `N`이라고 했을 때:

```text
O(N)
```

의 연산이 필요하다.

### Sliding Window

기존 합계를 저장하면 매 입력마다 필요한 핵심 연산은 다음과 같다.

```text
Sum -= Old Data
Sum += New Data
Average = Sum / Count
```

따라서 데이터 추가 및 평균 계산을:

```text
O(1)
```

로 처리할 수 있다.

Window Buffer를 위한 공간 복잡도는:

```text
O(N)
```

이다.

## 임베디드 활용

Moving Average Filter는 센서값에 포함된 순간적인 노이즈를 줄이는 데 활용할 수 있다.

* 온도 센서
* 습도 센서
* ADC 측정값
* 조도 센서
* 거리 센서
* 압력 센서
* 전압 및 전류 측정
* 배터리 전압 측정
* 아날로그 조이스틱
* 각종 환경 센서

특히 MCU에서 ADC 또는 센서 데이터를 주기적으로 읽는 경우 적은 연산량으로 데이터를 안정화할 수 있다는 장점이 있다.
